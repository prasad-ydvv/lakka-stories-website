configuration, order-request Edge Function and manager files.

Install:
1. Back up the currently working website folder.
2. Extract this ZIP into a new folder.
3. Open lakka-stories-website-main in VS Code.
4. Start Live Server and inspect desktop and mobile widths.
5. Test catalogue, product detail, cart, checkout and manager workflow.
Do not deploy until browser checks are complete.
