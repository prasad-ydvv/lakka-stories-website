LAKKA STORIES — Customer Website Release Package

Contents:
- index.html: approved cream, maroon and gold customer-facing catalogue design
- images/: existing local site images kept for reference/future use

Important before publishing:
1. This website reads only from Supabase public.public_catalogue. Products must be published in the private manager to appear.
2. It contains the Supabase project URL and publishable key only. Never put database passwords, service-role keys, or secret keys in this folder.
3. Confirm the WhatsApp number in index.html is the business number you want customers to contact.
4. Test one product image and one WhatsApp enquiry before announcing the site.
5. Do not publish unverified product names, materials, dimensions, authenticity claims, reference prices, or discounts.
6. This package has not been uploaded to GitHub Pages or your live domain. Your existing live website is unchanged.

Deployment:
Upload the contents of this folder (index.html and images folder) to your chosen commercial-friendly static host or replace the current repository files only after a final test. Keep a copy of the old website first.
