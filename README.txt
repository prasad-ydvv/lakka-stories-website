LAKKA STORIES — Collection price-card update

Replace your existing repository root index.html with the included index.html.
Do not replace product.html or other files for this change.

What changed:
- Collection cards show selling price prominently.
- A crossed-out reference price and discount badge appear only when reference_price > selling_price.
- Savings in rupees are shown only for a valid reference-price comparison.
- Collection cards link to product.html?id=<product id> using View Details.
- Responsive grid: 5 columns on wide desktop, 4/3 on smaller laptop/tablet widths, and 2 on mobile.
- Existing hero, story, filters, contact section, footer, Supabase query and product data fields are preserved.

Before publishing, make sure reference_price is a genuine, substantiated price and the discount is valid. No discount is shown if the reference price is missing or not higher than the selling price.
