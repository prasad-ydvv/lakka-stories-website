LAKKA STORIES — COMPLETE WEBSITE PACKAGE

This is the complete functional website package styled to match the approved
generated homepage reference.

Included:
- index.html homepage with hero, category cards, Etikoppaka craft panel,
  searchable/filterable catalogue, Our Story, WhatsApp enquiry and footer.
- Product detail page, cart, checkout and cart.js.
- Existing product photos and hero banner.
- Approved reference-derived decorative image assets for gift box, rocking horse,
  decorative pot, Etikoppaka bull/rings and village illustration.
- Supabase configuration and submit-order-request Edge Function.
- Manager dashboard and phase setup SQL/readme files.

Responsive design:
- Desktop catalogue: five columns.
- Tablet catalogue: four columns.
- Mobile catalogue: two columns.
- Interest cards stack cleanly on mobile.
- Hover text remains visible in maroon.

Important:
The decorative homepage images were cropped from the approved generated design
reference. The original product catalogue photographs are retained. The package
does not mean the website is deployed or that live order processing has been
tested in your hosting environment.

Install:
1. Keep a backup of your current website.
2. Extract this ZIP.
3. Open the lakka-stories-website-main folder in VS Code.
4. Run index.html with Live Server.
5. Test product detail, category filters, add-to-cart, cart quantities,
   checkout validation, order submission and manager WhatsApp draft.
6. Deploy only after local tests pass.
